# Asset Workbench

Headless and in-editor asset operations for scripts and AI agents: export, create, edit, migrate and audit Unity assets through one command line, `Scripts~/uaw.py`.

Open `Window > Asset Workbench` for the queue state and run logs, and its **Copy uaw.py** button to put the wrapper at the project root.

Documentation: the `Docs/` folder of the repository, starting with `Docs/AI-Guide.md`.
